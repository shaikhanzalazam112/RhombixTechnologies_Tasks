# Month 2 - Task 2: Tri-Fold Brochure Design

This project was completed as part of my Graphic Designing Internship at Rhombix Technologies.

The task involved designing a professional tri-fold brochure for a fictional fast-food brand called Burger Hub. The brochure includes:

* Front Cover Design
